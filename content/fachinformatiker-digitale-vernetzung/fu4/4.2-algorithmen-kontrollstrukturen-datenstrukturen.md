# Thema 4.2 — Algorithmen, Kontrollstrukturen und Datenstrukturen

## Theorie

### Was ist ein Algorithmus?

Ein **Algorithmus** ist eine eindeutige, endliche Folge von Anweisungen, die ein Problem löst oder eine Aufgabe erledigt. Die Berufsbildposition „Entwickeln, Erstellen und Betreuen von IT-Lösungen" (§ 4 Abs. 2 Nr. 4 FIAusbV) verlangt im Ausbildungsrahmenplan unter anderem, Algorithmen zu formulieren und Anwendungen in einer Programmiersprache zu erstellen. Das gilt in allen vier Fachrichtungen: vom Sortieren einer Kundenliste über die Berechnung eines Mittelwerts aus Maschinendaten bis zur Entscheidungslogik einer Anlagensteuerung.

Ein brauchbarer Algorithmus hat folgende Eigenschaften:

- **Eindeutig:** Jeder Schritt ist so genau beschrieben, dass keine Interpretationsspielräume bleiben.
- **Endlich (terminierend):** Er endet nach einer begrenzten Zahl von Schritten.
- **Ausführbar:** Jeder Schritt ist tatsächlich durchführbar, zum Beispiel von einer Maschine.
- **Allgemeingültig:** Er löst eine ganze Problemklasse, nicht nur einen Einzelfall (z. B. „Mittelwert einer beliebigen Liste" statt „Mittelwert der Zahlen 4, 5 und 6").
- **Determiniert:** Gleiche Eingaben führen zu gleichen Ergebnissen (bei den hier behandelten Verfahren).

Typisches Vorgehen: Problem verstehen und Ein- und Ausgaben festlegen, Lösungsidee entwerfen, in Pseudocode oder grafisch darstellen, in einer Programmiersprache umsetzen, mit Testdaten prüfen.

### Variablen, Datentypen und Operatoren

Eine **Variable** ist ein benannter Speicherplatz für einen Wert, der sich im Programmverlauf ändern kann. Eine **Konstante** behält ihren Wert. Jeder Wert hat einen **Datentyp**; die gängigen Grundtypen sind:

- **Ganzzahl** (int), z. B. 5 oder -12
- **Gleitkommazahl** (float), z. B. 3.14
- **Zeichenkette** (string), z. B. "Sensor-17"
- **Wahrheitswert** (bool): wahr oder falsch

Typen bestimmen, welche Operationen sinnvoll sind: Man kann Zahlen addieren, Zeichenketten aneinanderhängen. Die Typumwandlung (*Casting*) macht aus `"12"` die Zahl `int("12")`, also 12. Wichtige Operatoren sind Rechenoperatoren (`+`, `-`, `*`, `/`), die ganzzahlige Division und der Rest (in Python `//` und `%`: `7 // 2` ergibt 3, `7 % 2` ergibt 1), Vergleichsoperatoren (`==`, `!=`, `<`, `>`) sowie logische Operatoren (`and`, `or`, `not`). Achtung: Ein einzelnes `=` ist die Zuweisung, `==` der Vergleich. Zuweisungen wie `x = x + 1` sind keine mathematischen Gleichungen, sondern bedeuten: Berechne den Wert rechts und speichere ihn in `x`.

### Kontrollstrukturen

Jedes Programm lässt sich aus drei Grundbausteinen aufbauen:

- **Sequenz:** Anweisungen werden nacheinander abgearbeitet.
- **Verzweigung (Auswahl):** Je nach Bedingung wird ein anderer Weg gewählt (`if`/`elif`/`else`).
- **Schleife (Wiederholung):** Anweisungen werden wiederholt, bis eine Bedingung erfüllt ist oder für jedes Element einer Menge.

```python
temperatur = 9.5
if temperatur > 8:
    status = "Alarm"
elif temperatur > 6:
    status = "Warnung"
else:
    status = "OK"
print(status)        # Ausgabe: Alarm
```

Bei der **Zählschleife** ist die Zahl der Durchläufe vorab bekannt, bei der **bedingten Schleife** hängt sie von einer Bedingung ab:

```python
summe = 0
for i in range(1, 5):     # i nimmt die Werte 1, 2, 3, 4 an
    summe = summe + i
print(summe)              # Ausgabe: 10

rest = 10
while rest > 0:           # kopfgesteuert: Bedingung wird vor jedem Durchlauf geprüft
    rest = rest - 3
print(rest)               # Ausgabe: -2  (Werte: 10, 7, 4, 1, -2)
```

Eine typische Fehlerquelle ist die **Endlosschleife**: Die Schleifenbedingung wird nie falsch, weil die Variable in der Schleife nicht verändert wird. Bei der **fußgesteuerten** Schleife (in manchen Sprachen `do … while`; Python kennt sie nicht) wird die Bedingung erst nach dem Durchlauf geprüft, der Rumpf läuft also mindestens einmal.

### Funktionen

Eine **Funktion** bündelt Anweisungen unter einem Namen, damit sie wiederverwendet und getestet werden können. Sie erhält **Parameter** (Eingaben) und liefert optional einen **Rückgabewert**. Variablen, die innerhalb der Funktion angelegt werden, sind **lokal** und außerhalb nicht sichtbar. Gute Funktionen tun genau eine Sache und haben einen aussagekräftigen Namen.

```python
def rabatt(preis, prozent=10):
    return preis * (1 - prozent / 100)

print(rabatt(200))        # Ausgabe: 180.0
print(rabatt(200, 25))    # Ausgabe: 150.0
```

Der Parameter `prozent` hat einen Standardwert und kann beim Aufruf weggelassen werden.

### Einfache Datenstrukturen

Eine **Datenstruktur** organisiert mehrere Werte, damit man sie effizient speichern und verarbeiten kann.

- **Array/Liste:** geordnete Folge von Elementen, Zugriff über einen **Index**, der meist bei 0 beginnt. Bei `werte = [10, 20, 30, 40]` ist `werte[0]` gleich 10, `werte[-1]` in Python gleich 40, und `len(werte)` ist 4. Arrays haben in vielen Sprachen feste Größe und einen einheitlichen Typ, Listen sind meist dynamisch.
- **Stack (Stapel):** Zugriff nach dem Prinzip **LIFO** (*Last In, First Out*). Das zuletzt abgelegte Element wird zuerst entnommen. Typisch: Rückgängig-Funktion (Undo), Aufrufstapel von Funktionen. Operationen heißen üblicherweise `push` (ablegen) und `pop` (entnehmen).
- **Queue (Warteschlange):** Zugriff nach dem Prinzip **FIFO** (*First In, First Out*). Das älteste Element kommt zuerst dran. Typisch: Druckaufträge, Support-Tickets, Nachrichten in einer Verarbeitungskette.
- **Dictionary (Assoziatives Array, Map):** Sammlung von **Schlüssel-Wert-Paaren**. Der Zugriff erfolgt über den Schlüssel statt über eine Position, z. B. Sensor-ID als Schlüssel und letzter Messwert als Wert.

```python
stapel = []
stapel.append(1); stapel.append(2); stapel.append(3)
print(stapel.pop())      # Ausgabe: 3   (zuletzt hinein, zuerst heraus)

from collections import deque
queue = deque()
queue.append("A"); queue.append("B"); queue.append("C")
print(queue.popleft())   # Ausgabe: A   (zuerst hinein, zuerst heraus)

messwerte = {"T-17": 4.2, "T-18": 5.1}
messwerte["T-19"] = 3.8
print(messwerte["T-18"])   # Ausgabe: 5.1
print("T-20" in messwerte) # Ausgabe: False
```

Die Wahl der Datenstruktur richtet sich nach der Zugriffsart: Reihenfolge wichtig und Zugriff über Position → Liste; Zugriff über einen Namen/Schlüssel → Dictionary; Abarbeitung in Eingangsreihenfolge → Queue; umgekehrte Reihenfolge → Stack.

### Algorithmen darstellen

Bevor man programmiert, hilft eine Darstellung unabhängig von der Sprache:

- **Pseudocode:** Textbeschreibung in knapper, programmähnlicher Sprache ohne strenge Syntax, z. B.:

```
Eingabe: Liste werte
summe <- 0
FÜR JEDES w IN werte:
    summe <- summe + w
WENN Anzahl(werte) > 0 DANN
    Ausgabe: summe / Anzahl(werte)
SONST
    Ausgabe: "keine Daten"
```

- **Programmablaufplan (PAP, nach DIN 66001):** grafische Darstellung mit genormten Symbolen: Oval für Start und Ende, Rechteck für Verarbeitung (Anweisung), Raute für Verzweigung (mit Ausgängen „ja" und „nein"), Parallelogramm für Ein- und Ausgabe, Pfeile für den Ablauf.
- **Struktogramm (Nassi-Shneiderman-Diagramm):** besteht aus ineinander verschachtelten Rechtecken ohne Pfeile. Sequenzen werden übereinander gestapelt, eine Verzweigung als zweigeteilter Block mit „ja"/„nein" dargestellt, eine Schleife als Block mit Bedingung und eingerücktem Schleifenrumpf. Struktogramme erzwingen strukturierten Aufbau, weil sie keine beliebigen Sprünge kennen.

Welche Darstellung gewählt wird, hängt vom Zweck ab: Pseudocode ist schnell geschrieben, PAP und Struktogramm eignen sich gut zur Besprechung und Dokumentation.

### Einfache Such- und Sortierverfahren

**Lineare Suche:** Man prüft die Elemente nacheinander, bis der gesuchte Wert gefunden ist. Sie funktioniert bei jeder Liste, im ungünstigsten Fall werden aber alle Elemente geprüft.

```python
def lineare_suche(liste, gesucht):
    for index, wert in enumerate(liste):
        if wert == gesucht:
            return index
    return -1

print(lineare_suche([12, 7, 30, 5], 30))   # Ausgabe: 2
print(lineare_suche([12, 7, 30, 5], 99))   # Ausgabe: -1  (nicht gefunden)
```

**Binäre Suche:** Setzt eine **sortierte** Liste voraus. In jedem Schritt wird das mittlere Element mit dem gesuchten Wert verglichen und damit eine Hälfte des Suchbereichs verworfen. Bei 1.000.000 sortierten Einträgen genügen dadurch etwa 20 Vergleiche statt bis zu 1.000.000.

```python
def binaere_suche(liste, gesucht):
    links = 0
    rechts = len(liste) - 1
    while links <= rechts:
        mitte = (links + rechts) // 2
        if liste[mitte] == gesucht:
            return mitte
        elif liste[mitte] < gesucht:
            links = mitte + 1
        else:
            rechts = mitte - 1
    return -1

print(binaere_suche([3, 8, 15, 21, 34, 55, 89], 34))   # Ausgabe: 4
print(binaere_suche([3, 8, 15, 21, 34, 55, 89], 10))   # Ausgabe: -1
```

**Sortierverfahren:** Einfache Verfahren wie *Bubblesort* (benachbarte Elemente werden vertauscht, wenn sie in falscher Reihenfolge stehen), *Selectionsort* (das kleinste Restelement wird nach vorn geholt) oder *Insertionsort* (jedes Element wird an der richtigen Stelle in den bereits sortierten Teil eingefügt) sind leicht verständlich, aber bei großen Datenmengen langsam, weil der Aufwand etwa mit dem Quadrat der Elementzahl wächst.

```python
def bubblesort(liste):
    n = len(liste)
    for durchlauf in range(n - 1):
        for i in range(n - 1 - durchlauf):
            if liste[i] > liste[i + 1]:
                liste[i], liste[i + 1] = liste[i + 1], liste[i]
    return liste

print(bubblesort([5, 2, 9, 1]))   # Ausgabe: [1, 2, 5, 9]
```

In der Praxis nutzt man die in der Sprache vorhandene, optimierte Sortierfunktion (in Python `sorted(...)` bzw. `liste.sort()`); die einfachen Verfahren dienen dem Verständnis von Algorithmen.

#### Q-4.2-14 · Ablaufstrukturen
**Anweisung:** Ordne die Darstellung der passenden Ablaufstruktur zu.
- Die Anweisungen stehen im Struktogramm einfach übereinander → Sequenz
- Mehrere Anweisungen werden nacheinander ausgeführt → Sequenz
- Zweigeteilter Block mit „ja" und „nein" → Verzweigung
- WENN … DANN … SONST → Verzweigung
- Block mit Bedingung und eingerücktem Rumpf, der wiederholt wird → Schleife
- FÜR JEDES w IN werte → Schleife
**Erklärung:** Strukturierte Programme bestehen aus drei Grundbausteinen: Sequenz (Anweisungen nacheinander), Verzweigung (je nach Bedingung ein Zweig, im Struktogramm ein zweigeteilter Block) und Schleife (Wiederholung eines Rumpfes, im Struktogramm ein Block mit eingerücktem Schleifenrumpf).

#### Q-4.2-15 · Ablaufstrukturen
**Anweisung:** Ordne die Codeausschnitte und Beschreibungen der passenden Ablaufstruktur zu.
- int a = 5; int b = a * 2; → Sequenz
- Zuerst wird eingelesen, dann berechnet, dann ausgegeben → Sequenz
- if (summe > 100) { rabatt = 5; } else { rabatt = 0; } → Verzweigung
- if x < 0: … elif x == 0: … else: … → Verzweigung
- for (int i = 0; i < 10; i++) → Schleife
- while (rest > 0) → Schleife
**Erklärung:** if/else und elif-Ketten wählen je nach Bedingung einen Zweig (Verzweigung), for und while wiederholen einen Rumpf (Schleife), und Anweisungen ohne Steuerwort laufen einfach nacheinander ab (Sequenz).

#### Q-4.2-16 · Ablaufstrukturen
**Anweisung:** Bei der Brevanta wird eine Funktion zur Rechnungsberechnung als Struktogramm entworfen. Ordne jeden Teilschritt der passenden Ablaufstruktur zu.
