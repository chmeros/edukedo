# Umsetzung Paket B: Ersetzungsliste für Fachgespräch-, Fallaufgaben- und Glossar-Dateien

Stand 11.10.2026. Diese Änderungen betreffen Dateien (`fachgespraech.md`, `fallaufgaben.md`, `glossar.md`), die parallel von anderen Paketen bearbeitet werden und daher in Paket B nicht direkt geändert wurden. Die Themen-Dateien (Theorie, Karteikarten, Quiz) von Paket B sind bereits geändert. Je Block gilt: `ALT` ist ein einzeiliger, eindeutiger Teilstring (oder eine vollständige Zeile) der genannten Datei, `NEU` der Ersatztext. Für das Glossar gibt es in Paket B keine Änderungen (per Suche in allen `glossar.md` geprüft: keine Treffer zu Aufbewahrung, Offenlegung, CISG, Prokura, Ursprungszeugnis, Transithandel, Zollwert, Körperschaftsteuer, Publizität, Anfechtung, Verzug, Vertragsstrafe, Eigentumsvorbehalt, Produkthaftung, CMR, Lieferkette, Einfuhrumsatzsteuer, Verjährung, Gewährleistung, Grundsteuer).

Rechtsnahe Inhalte (R4): KI-Prüfung, keine Rechtsberatung; vor dem Einspielen juristisch gegenlesen.
